# Release Checklist

- [ ] Full test suite passes.
- [ ] E2E tests pass.
- [ ] Security scan reports zero real secrets.
- [ ] Database migrations are continuous.
- [ ] Wheel and source distribution build successfully.
- [ ] Wheel smoke test runs outside the source tree.
- [ ] README, SECURITY.md, and CHANGELOG.md are current.
- [ ] Demo can be created and reset.
- [ ] Known limitations are documented.
- [ ] Release tag and upload are performed manually by the project owner.
