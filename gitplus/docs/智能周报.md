# 智能周报助手

智能周报助手位于 `/smart-weekly`，用于将指定时间范围内可验证的研发记录整理为可编辑周报。

## 使用流程

1. 选择起止日期，查看候选来源。
2. 勾选本次周报使用的 Git 提交、确认记录或工作日志。
3. 选择规则生成或 AI 生成，可填写补充背景。
4. 在草稿中继续使用自然语言指令优化内容，或直接编辑 Markdown。
5. 保存周报；确认后该版本标记为正式周报。
6. 需要修改时重新打开为草稿，完成编辑后再次确认。
7. 导出 Markdown 文件用于提交或归档。

## 事实与版本控制

- 周报保存选定的来源 ID，便于追溯内容依据。
- 未选择任何事实来源时，系统不会生成周报。
- 周报有 `draft` 和 `confirmed` 两种状态。
- 每次保存与状态变更都会更新版本号；已确认周报被编辑时会回到草稿状态。
- AI 调用失败时，系统可回退到本地规则生成。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/smart-weekly/sources` | 查询时间范围内的候选来源 |
| POST | `/api/smart-weekly/generate` | 生成周报草稿 |
| POST | `/api/smart-weekly/refine` | 按用户指令优化草稿 |
| POST | `/api/smart-weekly/save` | 保存草稿 |
| POST | `/api/smart-weekly/export` | 导出 Markdown |
| GET | `/api/smart-weekly/reports` | 查询已保存周报 |
| PUT | `/api/smart-weekly/reports/{id}` | 更新周报 |
| POST | `/api/smart-weekly/reports/{id}/confirm` | 确认周报 |
| POST | `/api/smart-weekly/reports/{id}/reopen` | 重新打开为草稿 |
| DELETE | `/api/smart-weekly/reports/{id}` | 删除周报 |
