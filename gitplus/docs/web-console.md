# 本地 Web 控制台

## 启动

```bash
gitplus web
gitplus web --port 8765
gitplus web --no-open
gitplus web --project /path/to/repository
```

服务仅监听 `127.0.0.1`，默认端口为 `8765`。启动后会生成一次性本地访问链接；使用 `--no-open` 时可手动打开该链接。按 `Ctrl+C` 停止服务，服务重启后会话自动失效。

## 页面与能力

- 仪表盘：展示当前项目、数据库和运行环境摘要。
- Git 工作台：查看仓库状态、受控 Diff、暂存区，执行安全扫描、提交信息生成和确认提交。
- 工作日志：新增、编辑、复制、筛选和删除结构化工作记录。
- 工作历史：统一查看 Git 提交、确认记录和工作日志，并按条件筛选与导出。
- 智能周报助手：选择来源、生成草稿、AI 优化、编辑、保存、确认和导出周报。
- 系统配置：查看配置来源，校验和预览变更，安全保存配置并恢复备份。

所有写操作均需要有效本地 Session；配置和业务写请求还需要 CSRF 校验。
